# Наша история

Агрегатор всех сайтов, сделанных для Сабины с 31 июля 2023 года.

Главный лендинг — лента времени по годам, бургер-меню со всеми страницами.
Каждый сайт открывается в оверлее внутри хаба, оригиналы не изменены.

**Живая версия:** https://sprinterz5.github.io/sabina-hub/
